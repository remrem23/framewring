## Not bundled

- **[Everything](https://www.voidtools.com/)** by voidtools is a separate program. Framewring only talks to it if you have installed it yourself.
- **GPU encoders** (Nvidia NVENC, AMD AMF, Intel Quick Sync) are provided by your graphics driver; FFmpeg uses them at runtime.

All product names and trademarks belong to their respective owners.

## Replacing FFmpeg

FFmpeg runs as a separate program. You can replace `ffmpeg.exe` and `ffprobe.exe` in the program's `ffmpeg\bin` folder
with your own build. If you cannot get the FFmpeg sources for the bundled version from the links above,
open an [issue](https://github.com/remrem23/framewring/issues) and they will be provided.

## Русский

**Сторонние компоненты**

Сам Framewring распространяется по лицензии [GNU GPL v3](LICENSE).
Сборки для Windows (установщик и портабл-архив) содержат также сторонние компоненты из таблицы выше.
Тексты лицензий входящих в сборку пакетов Python, самого Python (включая bzip2 и Tcl/Tk), OpenSSL (Apache 2.0) и уведомление
WebView2 SDK лежат в папке `licenses` (её создаёт `packaging/build.py`); лицензия FFmpeg и ссылки на его исходники — в `ffmpeg\`;
для остальных компонентов см. ссылки в таблице выше.

При запуске из исходников используются только сам Python, установленный тобой FFmpeg и, по желанию, pywebview.

### Что входит в сборку (кратко)

- **FFmpeg** (ffmpeg.exe, ffprobe.exe), сборка Gyan «full» — всё кодирование, декодирование, анализ и VMAF. GNU GPL v3.
  Исходники: [github.com/FFmpeg/FFmpeg](https://github.com/FFmpeg/FFmpeg), сборки Gyan и их исходники —
  [gyan.dev/ffmpeg/builds](https://www.gyan.dev/ffmpeg/builds/), [github.com/GyanD/codexffmpeg/releases](https://github.com/GyanD/codexffmpeg/releases).
- **Python 3.12** — PSF-2.0; в его составе OpenSSL 3 (Apache-2.0), libffi (MIT), zlib (zlib), bzip2 (BSD-подобная),
  xz/liblzma (0BSD / общественное достояние), expat (MIT), mpdecimal (BSD-2-Clause), Tcl/Tk (BSD-подобная),
  среда выполнения Microsoft Visual C++ (лицензия Microsoft на распространение).
- **pywebview** (BSD-3-Clause) — окно программы; его зависимости bottle (MIT), proxy_tools (MIT), typing_extensions (PSF-2.0).
- **pythonnet** и clr_loader (MIT) — мост к .NET-компоненту WebView2; их зависимости cffi (MIT-0) и pycparser (BSD-3-Clause).
- **Microsoft WebView2 SDK** (Microsoft.Web.WebView2.Core.dll, Microsoft.Web.WebView2.WinForms.dll, WebView2Loader.dll) — BSD-подобная лицензия Microsoft.
- **Загрузчик PyInstaller** — GPL-2.0-or-later с исключением для загрузчика.

Сама среда **Microsoft Edge WebView2 Runtime** в сборку не входит: она есть в Windows 11 (и в большинстве Windows 10)
или ставится с сайта Microsoft.

### Не входит в сборку

- **[Everything](https://www.voidtools.com/)** (voidtools) — отдельная программа. Framewring обращается к ней, только если ты сам её установил.
- **Кодеры видеокарт** (Nvidia NVENC, AMD AMF, Intel Quick Sync) предоставляет драйвер видеокарты; FFmpeg использует их во время работы.

Все названия продуктов и товарные знаки принадлежат их владельцам.

### Замена FFmpeg

FFmpeg работает как отдельная программа. Можно заменить `ffmpeg.exe` и `ffprobe.exe` в папке `ffmpeg\bin` программы
своей сборкой. Если по ссылкам выше не получается найти исходники FFmpeg для версии из сборки,
напиши в [Issues](https://github.com/remrem23/framewring/issues) — их предоставят.
