# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Подробная история разработки с замерами — в [DEVLOG.md](DEVLOG.md).

## [Не выпущено]

### Добавлено
- Название **Framewring Жмых** (рус.) / **Framewring** (англ.), номер версии в интерфейсе и консоли.
- Папка данных зависит от способа запуска: из исходников — рядом с `app.py`; портабл-сборка (рядом с exe лежит `portable.txt`) — `data\` рядом с exe; установленная сборка — `%APPDATA%\Framewring`.
- FFmpeg ищется и рядом с exe, и внутри сборки.
- **Своё окно программы** (движок Edge / WebView2) вместо консоли и вкладки браузера; при закрытии во время сжатия — вопрос «Остановить и выйти?». Если WebView2 нет — открывается браузер, как раньше. Повторный запуск поднимает уже открытое окно.
- Сборка в exe: `packaging/build.py` (PyInstaller onedir, FFmpeg рядом с лицензией GPL и ссылками на исходники), значок программы.
- В сборке без консоли журнал пишется в `framewring.log` в папке данных.

### Изменено
- Окно выбора файлов открывается внутри программы (раньше запускался отдельный Python — в exe так нельзя).

## [0.9.0] — 2026-11-08

Первая версия, подготовленная к публикации.

### Добавлено
- Поиск тяжёлых видео на дисках: индекс Everything или многопоточный обход; оценка экономии, дубликаты, монтажные кодеки.
- Сжатие на видеокарте Nvidia (AV1, H.265) и процессоре (x265, SVT-AV1); видеокарта рекомендуется по умолчанию.
- Тест на куске видео: прогноз размера и времени, VMAF.
- Очередь и история сжатия сохраняются между запусками; «Повторить» для неудачных файлов; «Показать сжатый / оригинал».
- Этап «Дописываю файл» с прогрессом; предупреждения о файле подкачки и свободном месте.
- Кнопка «Поддержать автора».

### Исправлено
- VMAF занижался (~75 вместо ~96) из-за сопоставления кадров по времени.
- Падение SVT-AV1 при нехватке памяти; разовые сбои памяти теперь повторяются.
- ffmpeg оставался работать после закрытия окна; два экземпляра делили один порт.
- Потеря готового файла, если его держал антивирус или плеер; коллизии имён результатов.
- Черезстрочное видео, субтитры MKV, нечётное разрешение, обложка вместо видео, дата файла.
